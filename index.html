Project Overview

This project develops an interactive investment analytics platform for analyzing historical security performance, risk, benchmark-relative returns, liquidity, dividends, stock splits, and corporate events.

Performance

Historical returns, annualized performance, active returns and growth analysis.

Risk

Volatility, drawdown, beta and risk-adjusted performance analysis.

Benchmark

Security performance compared with SPY and risk-free rate measures.

Corporate Events

Dividend history, dividend growth, stock splits and event analysis.

Project Architecture

The solution combines data preparation, data modeling, analytical calculations and interactive visualization.

Financial Data → Python / Power Query → Data Validation → Data Model → DAX Analytical Engine → Power BI / Deneb → Interactive Dashboard
